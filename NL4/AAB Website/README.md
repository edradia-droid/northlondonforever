# NL4

A static Arsenal-themed website built with plain HTML, CSS, and JavaScript.

## Run locally

```bash
npm start
```

Then open http://localhost:3000 in your browser.

## Files

- `index.html` — homepage
- `styles.css` — site styling
- `index.js` — interactive behavior
- `players.html` and related pages — additional content pages

## Notes

This project does not require a build step. It is served directly as static files.
